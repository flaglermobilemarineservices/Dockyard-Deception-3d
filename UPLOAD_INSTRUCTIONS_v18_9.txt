MULTIPLAYER
- Exactly 2 players
- Host plays Rick
- Joiner plays Gage
- Tap 2 PLAYER, host gets a room code, Gage joins with that code
- Rick and Gage have solid collision and cannot run through each other
- Chas remains host-controlled and is synchronized to Gage's device
- Multiplayer uses an online peer-to-peer connection and needs internet access

SPARK PLUG GAME
- LEFT swipes remove each plug
- RIGHT swipes install
- Final controlled RIGHT swipe tightens it
- 3 wrong-direction swipes fails the current plug
- Over-hard final tightening snaps the plug and fails the current plug
